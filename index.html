Safety AR Goggles

Problem Statement

How can we make the Fabrication Laboratory safer and more independent for users to operate equipment?

Project Background

This project was developed to promote safety in the school's Fabrication Laboratory (FabLab) and make FabLab users more independent and confident using the equipment. The prototype goggles utilize computer vision to detect hazardous situations in real-time and alert users immediately.

Tech Stack

Hardware: ESP32 camera

Machine Learning: YoloV5 for object detection

Alert System: Visual and haptic feedback

How It Works

The live feed from the ESP32 camera mounted on a bandsaw is read by the YoloV5 model. The model detects if the user's hand is getting too close to the saw, prompting a warning on the screen of the safety goggles along with haptic feedback behind the ears.

Development Process

  • Collected over 300 images of users' hands on the bandsaw working on projects
  • Manually annotated images to mark hand locations on the working area
  • Trained YoloV5 model with the annotated dataset
  • Integrated model output with server to alert users with visual and haptic warnings

Does this work on ARM

Problem Statement

How can buyers of ARM-based Windows laptops determine software compatibility before making a purchase?

Project Background

This website is a searcher for potential buyers of laptops with ARM architecture and Windows OS. ARM-based Windows devices don't support all software made for the typical x64 architecture, which can be a significant barrier to adoption. This tool helps buyers check the availability of the software they use daily and find out when unavailable software will become available.

Purpose

This project was designed to complement Windows on Arm Ready Software. While that site had initially focused primarily on games, this project aimed to provide more comprehensive coverage including Microsoft Suites, Adobe Creative Cloud applications, and more.

Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: Python to read the Excel sheet containing list of applications

Status

Currently, this website's development has ceased as the original site has expanded to showcase more software categories. However, it served as a valuable resource during the early adoption phase of ARM-based Windows laptops.

Everflow - Expense Tracker

Problem Statement

How can users better understand and manage their personal finances with intuitive transaction tracking and budget planning?

Project Background

Everflow is a comprehensive Java-based expense tracking application designed to support personal financial management. The application empowers users to take control of their finances through intuitive transaction management and flexible budget planning.

Key Features

  • Create, modify, and delete transactions with ease
  • Customizable month-by-month budget planning
  • Define and manage income and expense categories
  • Recurring payment tracking for subscriptions
  • Goal-setting features with streak tracking
  • Visual charts displaying expenses in descending order to highlight spending patterns

Tech Stack

This application was developed with pure Java, XML, and an external chart library. As the primary goal of this project is to learn Java, common Android application development frameworks were not used.

Design Philosophy

Recorded transactions are displayed in descending order by default in charts, emphasizing users' largest expenditures. This design choice allows users to quickly identify major spending patterns and gain insights into their financial habits without having to manually review transactional records.

How can we provide caregivers of people with disability with a one-stop centre for information on caring for themselves and their patient or kin?

For my final year project in polytechnic, my group collaborated with SG Enable to create a chatbot to assist caregivers of individuals with autism

Beyond the chatting interface, the website includes:

  • Rating of responses + feedback channel
  • Editing of query + pagination of response versions
